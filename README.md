# What's new — Studio editor upgrade

**Upload ALL files in this folder to your repo root (replace the old ones).** New files: `editor-addon.js`, `graphics-pack.js`, `tpl-pack.js`, `tpl-pack2.js`.

## New left rail
- **Templates** – search, category chips (Astro, Review, Promo, Guide…), pick a colour theme, hover a card for *Add* / *Replace*. 38 new designs (daily tarot, stacked reviews, phone reviews, service card, free guide, moon & tithi, lucky number, mantra, consultation booking, do & don't, this-or-that, love match, announcement, dark showcase, mood board, bold doodle title, happy birthday, search-bar post, sun quote, save-the-date calendar, blue hook, photo collage, event launch, auspicious timings, maroon services, scrapbook, gradient quote, huge title, minimal journal, folder contents, plus a CTA set: follow page, follow dark, WhatsApp booking, save & share, book in 3 steps, limited slots).
- **Elements** – section rows with *See all*, search, recently-used, drag & drop onto the canvas. **~110 new graphics**: 3D stickers, emoji characters, tarot/astro art, Assam & festival (japi, gamosa border, dhol, tea, rangoli, marigold garland…), frames, 13 full-page patterns, doodles, social badges.
- **Text** – heading/subheading/body, 14 ready-made text styles, font browser (+8 new Latin fonts).
- **Uploads** – your images, drag/drop or Ctrl+V paste.
- **Background** – colours, gradients, patterns, photo background, "apply to all slides".
- **Brand** – brand colours, logo, brand fonts, {{handle}} / {{phone}}.
- **Tools** – shapes, QR code generator, grid & margins overlay, Present.

## New editing features
- **Resize** (header): Post 4:5, Square, Story 9:16, Pinterest, Landscape, Facebook, A4 or custom height; all slides adapt, with Undo.
- **Rotate** any element (↻ handle, Shift = 15° steps, or type an angle).
- **Floating mini-toolbar**, **right-click menu**, **Layers tab** (show/hide, lock, reorder), **Quick colours** strip.
- **Present** mode, Ctrl+scroll zoom with % display, Ctrl+D duplicate, Ctrl+[ ] layer order, "Saved" indicator.

Older documentation follows.

## Backup / import fix
Project ▸ Export now stores which set the project belongs to (weekly, monthly, transit, nakshatra, carousel) and the slide labels. Project ▸ Import accepts any number of slides (older exports are recognised automatically), switches to the right set, and shows a clear message if a file can't be read. Note: a browser only keeps its own work — to see a design in another browser, export in the first and import in the second.
